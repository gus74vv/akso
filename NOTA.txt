## Build / deploy (resumen operativo)

```sh
# Firmware (toolchain x86 GCC 8, corre bajo Rosetta). El toolchain no está en el
# working tree: recuperarlo de la historia del repo.
git checkout 2937859 -- external/gcc-arm/mac/gcc-arm-none-eabi-8-2019-q3-update
export PATH="$PWD/external/gcc-arm/mac/gcc-arm-none-eabi-8-2019-q3-update/bin:$PATH"
cd axoloti/firmware && make            # + (cd mounter && make), (cd flasher && make)

# Jar Java (JDK 11 arm64)
cd axoloti && JAVA_HOME=../external/jdks/mac_arm64/*/ ant
zip dist/Axoloti.jar org/usb4java/osx-aarch64/libusb4java.dylib   # ¡re-inyectar la dylib!
```

**Deploy del firmware: copiar el SET COMPLETO** (`bin` + `elf` + `hex` + `map` +
`dmp` + `list`) a `<bundle>/Contents/Resources/firmware/build/`, y reiniciar el
app. Con sólo el `.bin` el patch se linkea contra un `.elf` viejo
(`--just-symbols`) y crashea al go-live.

## Hardware / recovery

- Para entrar en DFU: **switch 1 apretado al conectar** (bootloader ROM).
- Rescue: **Board → Flash (rescue)** en el patcher (usa STM32CubeProgrammer).
  Suele requerir **power cycle sin switch 1** después para que arranque el firmware.
- Antes de cualquier experimento de flasheo: dump completo del flash + readback
  + `cmp` (ver `docs/DFU-WRITE-INCIDENT.md`).
